# TokenHalo

TokenHalo is a distributed data aggregation system that processes and manages large datasets in real-time, utilizing auto-scaling architecture.

With TokenHalo, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/TokenHalo.git`
2. `cd TokenHalo`
3. Install in editable mode: `pip install -e .`

## Configuration

TokenHalo is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
